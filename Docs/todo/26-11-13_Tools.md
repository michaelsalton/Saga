Level design

Play from here. Enters Play mode with the player placed at the Scene view camera, instead of at the spawn point. For a first-person game this is usually the biggest time-saver, because you stop walking across the map to check one corner. How it works: the menu item saves the camera's position in SessionState (editor storage that survives entering Play mode), then calls EditorApplication.EnterPlaymode(). A [RuntimeInitializeOnLoadMethod] hook (a static method Unity calls on its own when Play starts) reads that position and moves the player. The hook has to live in an assembly that can see your player code, which is Saga.Gameplay.
Drop to ground. Raycasts each selected object straight down and puts it on the first surface hit, with an option to tilt it to the surface normal. Unity's surface snap (Ctrl+Shift while dragging) only works while you're dragging one object; this fixes 50 floating parking meters in one click.
Randomize rotation / scale. Random Y rotation and a small random scale across the selection. You'd use it on the 120 trees, which are only two models, so they don't read as copies.
Replace with prefab. Swaps every selected object for another prefab and keeps each one's transform. Useful when you upgrade a placeholder or switch car variants.
Group selection. Creates a parent object at the centre of the selection and moves the selection under it. Unity has no built-in Ctrl+G for this.
Player-scale reference. Places a capsule that uses your player controller's height, radius and step height. Level designers call this metrics: you check doorways, ceilings and jump gaps against the real player size instead of eyeballing them. Read the numbers from the controller so the capsule can't drift out of date.
Measure. Shows the distance between two selected objects, or the bounds size of one, in the Scene view.
You already have LinePrefabSpawner and SagaSplineScatter in World/ for placing props along lines, so I've left out array/distribute tools.

Organization

Scene switcher. Lists the scenes in Build Settings (MainMenu, HotelLobby, Vice) and opens the one you click. It calls EditorSceneManager.SaveCurrentModifiedScenesIfUserWantsTo() first, so you get the usual save prompt. This fits the toolbar dropdown well since it's one click.
Find missing scripts / broken references. Lists every GameObject with a "Missing (Mono Script)" component, and every serialized field that points at a deleted asset. You've moved Saga and deleted a lot under Art/ recently, which is when these build up. GameObjectUtility.GetMonoBehavioursWithMissingScriptCount covers the first half.
Delete empty folders. Moves and deletes leave folders that contain only .meta files behind.
Naming check. Your assets use VICE_M_ (master material) and VICE_MI_ (material instance). This would list assets that don't follow the convention.
Hierarchy dividers. Creates an empty object named like --- Lighting ---, tagged EditorOnly so Unity strips it from builds. It gives the 300+ root objects headers.
Saved camera views. Stores Scene view camera positions per scene and jumps back to them, e.g. "lobby entrance", "street overview".
High-res screenshot. ScreenCapture.CaptureScreenshot(path, superSize) renders the Game view at 2–4× resolution, for devlogs or comparing renders before and after a shader change.
